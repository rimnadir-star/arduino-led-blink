# Arduino LED Blink

## Overview
This is my first Arduino project, built using an Arduino UNO R3. It introduces basic microcontroller programming and digital outputs.

## Components
- Arduino UNO R3
- LED
- Wires

## How It Works
The program configures a digital output and switches the LED on and off with a delay of 1 second between each state.

## What I Learned
- The purpose of `setup()` and `loop()`
- How to configure a digital output using `pinMode()`
- How `digitalWrite()` controls an output
- How `delay()` pauses program execution

## Future Improvements
- Use a push button to control the LED
- Experiment with different blinking intervals
- Build more advanced Arduino circuits
